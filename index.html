Timeline Desktop Controls

Add the same group-based keyboard navigation to the new game/video timeline.

What changes

  • A period-anchor button group: Q1–Q4 and all available overtime periods.
  • Tab and Shift+Tab move between groups and timestamp fields.
  • Arrows, Home/End and 1–9 choose a period or focus an action.
  • Enter or Space activates Start game, Mark incident, period marking and other actions.
  • Selecting a period highlights its anchor row; Tab then reaches that row’s editable timestamps.
  • Other period rows stay visible but are skipped by Tab until selected.

Safety: arrow or number navigation alone never starts the game or marks an incident. Typing numbers in timestamp fields still enters text.
